# Student Performance Prediction 📊

## Project Overview
Student Performance Prediction is a beginner-friendly Machine Learning project that predicts a student's exam score using study hours and previous academic scores.

The project uses Linear Regression to understand the relationship between input features and exam performance.

## Objectives
- Understand the basics of Machine Learning.
- Learn how to prepare and split a dataset.
- Train a Linear Regression model.
- Evaluate model performance.
- Predict an example exam score.
- Visualize actual and predicted scores.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Algorithm
**Linear Regression**

Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values.

## Dataset
This project uses a small, illustrative dataset containing:
- Study Hours
- Previous Score
- Exam Score (target variable)

**Note:** The data is created for educational demonstration and does not represent real students.

## Project Workflow
1. Create and load the dataset.
2. Select input features and the target variable.
3. Split the data into training and testing sets.
4. Train the Linear Regression model.
5. Evaluate predictions using Mean Absolute Error and R-squared.
6. Predict an example student's score.
7. Visualize actual versus predicted scores.

## Evaluation Metrics
- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted scores.
- **R-squared (R²):** Measures how well the model explains variations in the target values.

Actual results are displayed when the notebook is executed.

## How to Run
1. Open `student_performance_prediction.ipynb` in Google Colab.
2. Run each code cell in order.
3. Review the evaluation metrics, prediction, and plot.

## Limitations
- The dataset is very small and illustrative.
- The model is not validated for real-world student assessment.
- Predictions are for educational purposes only.
